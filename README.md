# 提示词预览与历史

为 DSH 0.2.1 的输入框提供两个功能：回答完成后的下一句用户提示词预览，以及 ↑/↓ 历史回顾。

- 只有 `turn/end` 的结果为 `completed`、存在本轮完整回答、会话已空闲且没有排队输入时，才请求预测。中途的工具调用、消息渲染和输入框聚焦都不会触发。
- 使用会话的 `modelSelection.next` / `lastUsed`，不回退到全局默认模型。保持相同 provider 和 model；模型支持时使用较低的推理强度，单次输出预算为 2048 tokens、超时 60 秒。每轮、每个模型成功生成的建议会复用；输入清空只恢复缓存，不重复调用模型。尚未完成的请求被用户编辑取消后，清空输入允许重新请求。调用失败或空结果不自动重试。
- 预测上下文来自会话事件投影中最近 8 条用户与助手文字，明确区分角色，省略工具输出、思维过程和系统提示。独立请求要求从用户视角起草下一句话。
- 未生成建议或正在生成时，保留输入框原本的灰色占位提示。建议就绪后隐藏原占位文字，显示灰色建议，开始输入或忽略后恢复原生输入框。
- 预览挂在 `conversation.input.overlay` 槽位中。仅在建议就绪时，将该原生零高度浮层与编辑器合为同一 Grid 行，建议的自然换行撑高输入框和工具栏位置；不设置预览固定高度或单独滚动区。布局规则由组件标记限定，组件卸载后随样式一起清理。没有全局浮层、固定定位、DOM 注入、聊天 DOM 监听或轮询。
- 预览不写入草稿，不自动发送。输入框聚焦后按 **Tab** 采纳，按 **Esc** 忽略；这两个动作会消费当前建议。普通输入、粘贴、输入法组合和历史回顾仅隐藏已生成建议，清空草稿后恢复；进行中的预测会取消。新一轮或会话/模型上下文变化会清除旧建议。离开输入区域时隐藏结果并取消进行中的请求。
- **↑** 回顾较早的提示词，**↓** 返回较新的提示词，翻到底恢复原草稿。输入前缀后 ↑ 只回顾匹配项。开始编辑即退出回顾；普通多行草稿中间的方向键、选区、引用菜单和输入法不受影响。
- 历史取自当前会话最新 200 条实际用户文字消息，连续重复合并；通过会话日志恢复，刷新后仍可回顾。文件、图片本体不会重建为附件。带引用 chip 的当前草稿保持原生编辑行为。

预测会使用当前模型的额度。模型未能输出合适的建议或调用失败时，本轮不显示建议。生成质量取决于当前模型，插件会过滤常见的助手口吻与无效格式。

## 安装与维护

在 DSH 左侧栏打开 **插件 → 添加插件 → 安装第三方插件**，填入：

```text
https://github.com/catwithoutear/dsh-prompt-assist.git
```

安装并启用后，插件显示名称为「提示词预览与历史」，包名为 `@local/dsh-prompt-assist`。也可以通过插件管理器安装本地检出目录。若已启用 `dsh-prompt-history`，先停用旧插件，避免两套键盘监听和预览重叠。旧插件可随时重新启用；本插件没有修改旧插件代码或配置数据。

开发命令：

```sh
npm ci
npm run build
npm test
npm run check
```

`client.js` 是由 `core.js`、`remote.js`、`preview-state.js`、`client-entry.js` 生成的浏览器产物。Host 为 `index.js`。依赖仅为 Zod 与 DSH 自带的 Typert 协议。没有安装脚本、额外模型配置、侧聊、剪贴板功能、历史补全或设置页面。

测试通过当前 DSH profile 解析已经安装的 Harness 依赖；独立检出需要安装清单中的依赖。更新源码后应重新构建，再通过 DSH 插件管理器应用更新；替换已加载的 Host 模块可能需要重启 DSH。

参考了 [Xiaofei-fei/dsh-prompt-history](https://github.com/Xiaofei-fei/dsh-prompt-history) 的使用方式与公开接口，本插件为独立实现。

## Codex 参考范围

本次核对了 [openai/codex PR #23976](https://github.com/openai/codex/pull/23976) 的代码与测试。它明确保留已显示的建议，普通输入时隐藏，清空草稿后恢复；Tab 采纳只填入草稿，不发送。不过该 PR 已关闭且未合并，不能称为当前 Codex 主分支或桌面版的实现。

本插件参考其中“缓存与显示资格分离”的行为。用户在生成完成前取消请求、随后清空草稿时，允许重新请求，是本插件为恢复流程补足的策略；失败和空结果仍不自动重试。没有引入该 PR 中其他会话模式或接口。

1.0.2 同时更新了 Host 的取消缓存逻辑和 Client 的预览状态。更新后建议重启 DSH 一次，确保两端都加载新模块；仅刷新页面不能确认已加载的 Host JavaScript 已更新。
